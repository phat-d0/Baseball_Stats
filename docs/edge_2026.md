`scripts/blend_variants.py` scores each variant on the same rows. Let `d = logit(model) −

Findings:

- **Per-line is the worst.** It overfits. On strikeouts the 6.5 line gets a model weight
  of 0.95 and a DK weight of −0.04 from about 600 rows. It makes five times the bets and
  is dishonest: it says 55% and wins 52%.
- **Per-side** finds the model's strikeout tilt toward unders worth more than its tilt
  toward overs (0.26 vs 0.14 on `d`). That matches the backtest note. But the log loss
  gain is 0.00013 with a range that crosses zero. Its +7.8% at ≥ 0% comes from the
  0–1% band (97 bets, +13%), the smallest edges, which looks like luck. At ≥ 1% it
  returns less than base.
- **Shrinking big disagreements** gets a negative weight as expected (hitters −0.44,
  strikeouts −0.09 on `d·|d|`), but it doesn't improve the test log loss.
- **Confirmed vs projected lineups** can't be tested on historical prices: they're
  graded with the lineups actually used, so every row is "confirmed". The live log has
  `lineup_confirmed` but only 39 graded rows. Revisit at a few hundred closing lines.

**Decision:** keep `base`, the simplest version. Nothing else wins out of sample.
`blend.json` is unchanged.

## 4. Refit pipeline

`scripts/refit_blend.sh [weights] [report]` (defaults: `baseball_stats/blend.json`,
`docs/edge_refit.json`):

1. Fetches `odds-history` (the one-hour snapshots in its root) and the `odds-log` price
   log.
2. Recomputes walk-forward model chances with the current code.
3. Adds the live log's graded closing lines (taken at most 90 minutes before first
   pitch).
4. Fits the blend on everything.
5. Scores it walk-forward, each month fitted only on earlier months.

It takes ~20 minutes on 4 cores. **Rerun it after any Strikeouts or Hitters model PR
merges**, because the weights depend on the model. Commit the new `blend.json` only if
the walk-forward table holds up.

Test run today. I wrote the weights to scratch, not to `blend.json`. It used 2,338 games
and 45,386 lines. The live log added 0 lines: its latest pulls so far are 2.7–7.8 h
before first pitch, so none count as closing.

- Hitters: 0.19 model / 0.87 DK.
- Strikeouts: 0.21 / 0.85.

Walk-forward log loss:

| Month | Hitters: model / DK / blend | Strikeouts: model / DK / blend |
|---|---|---|
| 2025-09 | 0.6879 / 0.6846 / **0.6841** | 0.6937 / 0.6889 / **0.6874** |
| 2026-08 | 0.6891 / 0.6851 / **0.6850** | 0.6785 / 0.6806 / **0.6784** |
| 2026-09 | 0.6895 / **0.6863** / 0.6868 | 0.7081 / **0.6887** / 0.6905 |

The blend beats DraftKings in 2 of 3 months for each prop and loses in Sep 2026. In that
month the strikeout model was bad (0.7081) and its one-month weight was −0.04. Month-by-
month strikeout model weights swing from 0.0 to 0.52. The model adds a little on
average, but not reliably every month.
